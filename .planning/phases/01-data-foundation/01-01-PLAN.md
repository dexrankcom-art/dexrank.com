<task type="auto">
  <name>Task 2: Install Drizzle ORM and create database schema</name>
  <files>
    package.json
    src/db/index.ts
    src/db/schema.ts
    drizzle.config.ts
    .env.local
    .env.example
  </files>
  <action>
    1. Install Drizzle dependencies:
       `npm install drizzle-orm @neondatabase/serverless exponential-backoff zod`
       `npm install -D drizzle-kit dotenv tsx`

    2. Create .env.example with:
       ```
       DATABASE_URL=postgresql://user:pass@host/db?sslmode=require
       CRON_SECRET=your-secret-here
       ```

    3. Create .env.local (will be gitignored) with placeholder:
       ```
       DATABASE_URL=
       CRON_SECRET=
       ```

    4. Create src/db/schema.ts with tables from research doc:
       - chains: id, slug, name, chainId, logo, timestamps
       - protocols: id, defillamaId, slug, name, symbol, category, logo, url, description, timestamps
       - protocolChains: id, protocolId (FK), chainId (FK), timestamps, unique constraint on (protocolId, chainId)
       - protocolMetrics: id, protocolId (FK), tvl, tvlChange1h/1d/7d, volume24h/7d/30d, volumeChange1d/7d, chainTvls (jsonb), fetchedAt, timestamps
       - syncStatus: id, syncType (unique), lastSyncAt, lastSuccessAt, lastError, recordsProcessed, timestamps

       Use the exact schema from 01-RESEARCH.md, including:
       - `generatedAlwaysAsIdentity()` for primary keys
       - Reusable timestamps object with `$onUpdateFn`
       - Proper indexes on protocolMetrics (protocolId, fetchedAt)
       - Proper foreign key relationships with onDelete: 'cascade'

    5. Create src/db/index.ts with Neon HTTP connection singleton (from research):
       ```typescript
       import { neon } from '@neondatabase/serverless';
       import { drizzle } from 'drizzle-orm/neon-http';
       import * as schema from './schema';

       const sql = neon(process.env.DATABASE_URL!);
       export const db = drizzle(sql, { schema });
       ```

    6. Create drizzle.config.ts (from research):
       ```typescript
       import 'dotenv/config';
       import { defineConfig } from 'drizzle-kit';

       export default defineConfig({
         schema: './src/db/schema.ts',
         out: './drizzle',
         dialect: 'postgresql',
         dbCredentials: {
           url: process.env.DATABASE_URL!,
         },
         verbose: true,
         strict: true,
       });
       ```

    7. Add npm scripts to package.json:
       ```json
       "db:push": "drizzle-kit push",
       "db:studio": "drizzle-kit studio",
       "db:generate": "drizzle-kit generate"
       ```
  </action>
  <verify>
    - `npx tsc --noEmit` passes (no TypeScript errors in schema)
    - src/db/schema.ts exports: chains, protocols, protocolChains, protocolMetrics, syncStatus
    - src/db/index.ts exports: db
    - drizzle.config.ts exists with postgresql dialect
  </verify>
  <done>
    Drizzle ORM configured with full schema. Types are inferred from schema. Ready for database connection.
  </done>
</task>
