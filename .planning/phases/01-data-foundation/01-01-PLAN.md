  <action>
Create `src/db/schema.ts` with the complete schema from RESEARCH.md:

1. **chains table**: id, slug, name, chainId, logo, timestamps
   - Stores supported blockchain networks (Ethereum, Solana, Arbitrum, etc.)
   - slug is unique identifier

2. **protocols table**: id, defillamaId, slug, name, symbol, category, logo, url, description, timestamps
   - Stores DEX metadata
   - defillamaId and slug are both unique
   - Index on category for filtering

3. **protocolChains table**: id, protocolId, chainId, timestamps
   - Many-to-many between protocols and chains
   - Unique index on (protocolId, chainId)
   - Foreign keys with cascade delete

4. **protocolMetrics table**: id, protocolId, tvl, tvlChange1h/1d/7d, volume24h/7d/30d, volumeChange1d/7d, chainTvls (jsonb), fetchedAt, timestamps
   - Time-series metrics data
   - Indexes on protocolId and fetchedAt

5. **syncStatus table**: id, syncType, lastSyncAt, lastSuccessAt, lastError, recordsProcessed, timestamps
   - Tracks sync job status
   - syncType is unique (values: 'protocols', 'volumes', 'full')

Use reusable timestamps pattern:
```typescript
const timestamps = {
  createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).defaultNow().notNull().$onUpdateFn(() => new Date()),
};
```

Create `src/db/index.ts`:
```typescript
import { neon } from '@neondatabase/serverless';
import { drizzle } from 'drizzle-orm/neon-http';
import * as schema from './schema';

const sql = neon(process.env.DATABASE_URL!);
export const db = drizzle(sql, { schema });
```

Create `drizzle.config.ts`:
```typescript
import 'dotenv/config';
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  schema: './src/db/schema.ts',
  out: './drizzle',
  dialect: 'postgresql',
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
  verbose: true,
  strict: true,
});
```

Add npm scripts to package.json:
```json
"db:push": "drizzle-kit push",
"db:studio": "drizzle-kit studio",
"db:generate": "drizzle-kit generate"
```

  <action>
Create `src/db/seed.ts` that populates the chains table with the 10+ required networks:

```typescript
import { db } from './index';
import { chains } from './schema';

const CHAINS = [
  { slug: 'ethereum', name: 'Ethereum', chainId: 1 },
  { slug: 'solana', name: 'Solana', chainId: null },
  { slug: 'arbitrum', name: 'Arbitrum', chainId: 42161 },
  { slug: 'base', name: 'Base', chainId: 8453 },
  { slug: 'bsc', name: 'BNB Chain', chainId: 56 },
  { slug: 'polygon', name: 'Polygon', chainId: 137 },
  { slug: 'optimism', name: 'Optimism', chainId: 10 },
  { slug: 'avalanche', name: 'Avalanche', chainId: 43114 },
  { slug: 'zksync', name: 'zkSync Era', chainId: 324 },
  { slug: 'fantom', name: 'Fantom', chainId: 250 },
];

async function seed() {
  console.log('Seeding chains...');

  for (const chain of CHAINS) {
    await db
      .insert(chains)
      .values(chain)
      .onConflictDoUpdate({
        target: chains.slug,
        set: { name: chain.name, chainId: chain.chainId },
      });
  }

  console.log(`Seeded ${CHAINS.length} chains`);
}

seed()
  .then(() => process.exit(0))
  .catch((err) => {
    console.error('Seed failed:', err);
    process.exit(1);
  });
```

Add npm script to package.json:
```json
"db:seed": "tsx src/db/seed.ts"
```

Note: This requires DATABASE_URL to be set. The seed uses upsert so it's idempotent.
