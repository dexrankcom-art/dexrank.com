  <action>
    Implement Core Web Vitals reporting:

    1. Create `src/app/_components/web-vitals.tsx`:
       ```typescript
       'use client';

       import { useReportWebVitals } from 'next/web-vitals';

       export function WebVitals() {
         useReportWebVitals((metric) => {
           // In development, log to console for debugging
           if (process.env.NODE_ENV === 'development') {
             console.log('[Web Vital]', metric.name, metric.value, metric.rating);
             return;
           }

           // In production, send to Sentry for tracking
           // Sentry automatically captures these via Performance monitoring
           // For custom analytics, send via beacon:
           const body = JSON.stringify({
             metric: metric.name,
             value: metric.value,
             rating: metric.rating,
             page: window.location.pathname,
             id: metric.id,
           });

           // Use sendBeacon for reliable delivery on page unload
           if (navigator.sendBeacon) {
             navigator.sendBeacon('/api/analytics/vitals', body);
           }
         });

         return null;
       }
       ```

    2. Update `src/app/providers.tsx`:
       - Import WebVitals from './_components/web-vitals'
       - Add WebVitals component inside the provider tree (after ThemeProvider)
       - It renders null so doesn't affect layout

    Note: The /api/analytics/vitals endpoint doesn't need to exist yet - sendBeacon will silently fail if not present. This gives a hook point for future analytics.

    Alternative (simpler): If @vercel/analytics is preferred for Vercel deployment:
    - Install: `npm install @vercel/analytics`
    - Add `<Analytics />` to providers instead of custom WebVitals
    - This requires Vercel deployment but provides automatic dashboard
