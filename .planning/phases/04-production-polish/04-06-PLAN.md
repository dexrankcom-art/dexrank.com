# Plan 04-06: Social Sharing

## Objective

Generate dynamic Open Graph images for social sharing using Next.js ImageResponse, with brand-consistent styling for homepage, DEX pages, and chain pages.

## Requirements Addressed

- SOCIAL-01: All pages have Open Graph meta tags for social sharing
- SOCIAL-02: Twitter/X cards display rich previews with images
- SOCIAL-03: Dynamic OG images generated for DEX pages showing key metrics

## Context

Per RESEARCH.md: Use `ImageResponse` from `next/og` (built into Next.js 16). Important: In Next.js 16+, `params` is a Promise that must be awaited.

Brand colors from CONTEXT.md:
- Primary: Deep purple (hex: #1a0a2e for dark background)
- Accent: Bright green (hex: #4ade80)
- Note: OKLCH colors don't work in ImageResponse - use hex

OG image specs: 1200x630px, PNG format, flexbox layout only (no CSS grid).

```tsx
function formatNumber(num: number | null | undefined): string {
  if (!num) return '$0';
  if (num >= 1_000_000_000) return `$${(num / 1_000_000_000).toFixed(1)}B`;
  if (num >= 1_000_000) return `$${(num / 1_000_000).toFixed(1)}M`;
  if (num >= 1_000) return `$${(num / 1_000).toFixed(0)}K`;
  return `$${num.toFixed(0)}`;
}
```

```typescript
export async function getChainBySlug(slug: string) {
  const [chain] = await db
    .select()
    .from(chains)
    .where(eq(chains.slug, slug))
    .limit(1);
  return chain || null;
}

export async function getProtocolCountByChain(chainSlug: string) {
  const chain = await getChainBySlug(chainSlug);
  if (!chain) return 0;

  const [result] = await db
    .select({ count: sql<number>`count(*)::int` })
    .from(protocolChains)
    .where(eq(protocolChains.chainId, chain.id));

  return result?.count || 0;
}
```
