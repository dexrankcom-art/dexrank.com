# Plan 04-02: Page Transitions

## Objective

Implement smooth page transitions with CSS-based fade animations and loading states during route navigation.

## Requirements Addressed

- ANIM-01: Page transitions with smooth route animations (CSS fade, not View Transitions API per CONTEXT.md decision)
- TECH-04: All pages server-side rendered or statically generated (preserving existing ISR)

## Context

Per CONTEXT.md decision: Skip View Transitions API due to spotty browser support. CSS fade achieves same effect with better compatibility.

Plan 04-01 created the CSS keyframes (`animate-fade-in`) in globals.css. This plan uses Next.js `template.tsx` convention for page transitions and `loading.tsx` for route loading states.

Animation philosophy from CONTEXT.md: "Responsive, not reactive" — subtle fade + slight vertical shift (150-200ms).

## Tasks

<tasks>
<task id="1" title="Create page transition template">

Create `src/app/template.tsx`:

```tsx
/**
 * Template wraps each page and re-renders on navigation.
 * Used for page transitions - the template unmounts/remounts on route change.
 *
 * Using CSS animation from globals.css (Plan 04-01)
 * Respects prefers-reduced-motion automatically via CSS media query
 */
export default function Template({ children }: { children: React.ReactNode }) {
  return (
    <div className="animate-fade-in">
      {children}
    </div>
  );
}
```

This is intentionally simple - the CSS handles the animation. The `template.tsx` file has a special behavior in Next.js: it re-renders on every route change (unlike `layout.tsx` which persists), making it perfect for page transitions.

The `animate-fade-in` class (from Plan 04-01) applies:
- 0.2s duration
- ease-out timing
- translateY(8px) to translateY(0) movement
- opacity 0 to 1

The CSS already includes `@media (prefers-reduced-motion: reduce)` that disables the animation.

<task id="2" title="Create global loading skeleton">

Create `src/app/loading.tsx`:

```tsx
import { Skeleton } from '@/components/ui/skeleton';

/**
 * Global loading state shown during route transitions.
 * Uses shimmer animation from Plan 04-01.
 *
 * This loading.tsx applies to all routes. Individual routes can
 * have their own loading.tsx for more specific skeletons.
 */
export default function Loading() {
  return (
    <div className="container mx-auto px-4 py-8 animate-fade-in-simple">
      {/* Page title skeleton */}
      <Skeleton className="h-10 w-64 mb-6" />

      {/* Content area skeleton */}
      <div className="space-y-4">
        {/* Stats row */}
        <div className="grid grid-cols-2 md:grid-cols-4 gap-4">
          {[...Array(4)].map((_, i) => (
            <Skeleton key={i} className="h-24 rounded-lg" />
          ))}
        </div>

        {/* Table skeleton */}
        <div className="border rounded-lg p-4 space-y-3">
          {/* Table header */}
          <div className="flex gap-4 border-b pb-3">
            <Skeleton className="h-4 w-8" />
            <Skeleton className="h-4 w-32" />
            <Skeleton className="h-4 w-20 ml-auto" />
            <Skeleton className="h-4 w-20" />
          </div>
          {/* Table rows */}
          {[...Array(8)].map((_, i) => (
            <div key={i} className="flex gap-4 py-2">
              <Skeleton className="h-4 w-8" />
              <Skeleton className="h-4 w-40" />
              <Skeleton className="h-4 w-16 ml-auto" />
              <Skeleton className="h-4 w-16" />
            </div>
          ))}
        </div>
      </div>
    </div>
  );
}
```

Uses the simple fade without vertical movement (`animate-fade-in-simple`) since the skeleton itself is a placeholder - we don't want the skeleton to animate in dramatically.

</task>

<task id="3" title="Enhance Skeleton component with shimmer">

Update `src/components/ui/skeleton.tsx` to support shimmer animation:

```tsx
import { cn } from "@/lib/utils"

interface SkeletonProps extends React.ComponentProps<"div"> {
  /** Use shimmer animation instead of pulse. Default: true */
  shimmer?: boolean;
}

function Skeleton({ className, shimmer = true, ...props }: SkeletonProps) {
  return (
    <div
      data-slot="skeleton"
      className={cn(
        "rounded-md",
        shimmer
          ? "bg-gradient-to-r from-muted via-muted-foreground/10 to-muted bg-[length:200%_100%] animate-shimmer"
          : "bg-accent animate-pulse",
        className
      )}
      {...props}
    />
  )
}

export { Skeleton }
```

Changes:
- Added `shimmer` prop (default true) for configurable animation style
- Shimmer uses the left-to-right gradient animation from globals.css
- Falls back to pulse animation if shimmer=false
- Maintains backward compatibility with existing usage
