## Problem

No documented process for updating editorial content. As content grows to 100+ articles, need repeatable process for updates. Prevents mistakes and enables future contributors.

## Solution

Create SOP document covering:
1. When to update (new features, data changes, user feedback)
2. How to update (edit MDX, run checklist, commit, verify)
3. How to track what needs updating (content audit schedule)
4. How to handle outdated info (mark as outdated vs delete vs redirect)

Store in `/docs/CONTENT_SOP.md` or `.planning/` directory.
