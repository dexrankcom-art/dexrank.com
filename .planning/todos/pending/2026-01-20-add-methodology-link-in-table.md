## Problem

Users see DexRank scores but may not understand how they're calculated. The "How We Rank" page exists (Phase 3), but users need to discover it. Placing the link where users see scores builds trust.

## Solution

Add small info icon or "How we rank" link next to the "DexRank Score" column header in the rankings table. Clicking opens methodology page or tooltip explaining the algorithm basics.

Example: "DexRank Score (?)" where (?) links to /methodology
