## Problem

Without a quality checklist, editorial content (Editor's Take, guides) may ship with inconsistent quality, factual errors, or AI-sounding language. Need gates to catch issues before publish.

## Solution

Create checklist document covering:
- [ ] Facts verified against official sources
- [ ] No generic filler phrases ("in the world of crypto...")
- [ ] Specific data points included (not vague claims)
- [ ] Links to sources where appropriate
- [ ] Reads naturally (not robotic)
- [ ] Unique insight not found on competitor sites
- [ ] Affiliate disclosures present if needed
- [ ] Last updated date set

Use as manual review step before committing content.
